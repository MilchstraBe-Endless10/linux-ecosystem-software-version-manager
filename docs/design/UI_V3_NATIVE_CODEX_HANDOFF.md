### 1. Git 基线与保护

首先运行只读的 git status --porcelain=v1 -uall、git branch -avv、git remote -v（输出脱敏）、git rev-parse HEAD、git ls-remote --heads origin。核对本地和远端真实提交及祖先关系。2026-11-24 的远端 main 为 9312f8d6614e0c79c453f5ca0083e181fd475727；GUI 分支相对 main 领先 5 个提交。历史报告的本地 HEAD 不保证已推送。先保护大量已有未跟踪内容，不执行 clean/reset/stash/switch/checkout/merge/rebase，不创建覆盖性提交；需要同步时仅在明确授权范围内获取远端对象（不 prune），在独立目录或独立 worktree 对照。未经批准不合并或推送生产源码。读此分支和 GUI 分支文件，逐项比较概念与本地实现。

远端参考：feature/gui-fx-native-001 的 experiments/gui-qtquick/GUI_FIDELITY_STACK.md、MagicCore.qml、LightMotes.qml。其文档明确只针对旧公开 PoC，不等于已通过本地真实 GUI 验收。

### 2. 视觉与功能设计

批准首页的蓝紫青色光效、幻想场景、导航、字体层级、圆角、玻璃质感与整体构图保持一致。其余页面不复制首页大人物构图：背景收敛，主内容有高对比度，保留每个页面独特的视觉重心。先做 AI Agent/CLI，再做软件清单；再做更新任务（其独立候选待确认）；其余四页待独立高保真候选确认后逐页实施；同轮不要开发 PRD 未批准的功能。每页对照已确认的独立高保真视觉候选、必要状态图与组件图，禁止以简化 HTML 候选替代。以下仅是构图候选，以原文为准：

- 软件清单：玻璃数据工作台，紧凑可虚拟化列表、筛选与列管理、实例详情及已有项目审计；不把渠道候选叫上游最新版。
- AI Agent/CLI：左侧实例列表，右侧来源与实例对比、PATH 顺序及运行时证据；PATH 图只表达已知 GUI 捕获上下文，未知不猜测。
- 更新任务：可读的阶段轨道（发现/计划/预检/确认/执行/核验/留痕），实际批次及逐项阻断、失败和待核实；不展示虚假进度或开放未实现的执行。
- 来源与适配器：适配器星图/矩阵与可读的 D/V/P/E/A、真实检查、CLI 版本和兼容证据面板；未核实不显示兼容，启停不等于授权。
- 系统洞察：只对真实已提供指标绘图，空数据时展示原因与可用证据；没有采集器就不画虚假历史曲线或健康分数。
- 故障恢复：按任务证据显示失败阶段、组件变化、人工介入和恢复等级/点；未知不能显示可恢复，不新增一键回滚。
- 设置与偏好：分组显示已实现的频率/继承、日历、通知、免打扰、适配器开关、布局和动效偏好；待决时区/DST、F2、C2/B3 不冒充已实现。

### 3. 原生组件及动效

保留现有正式 SoftwareModel 接口与 C++ 安全判定，抽取可复用的 QML 设计 tokens、导航、图标、按钮、玻璃卡片、状态标签、虚拟化列表、证据面板。先探测本机已安装 Qt 模块，不自动安装。QtQuick 原生 Behavior/NumberAnimation/ColorAnimation/Transition；按钮 hover 120–160ms、press scale 0.98、导航滑块 180–220ms、详情面板 220–260ms（均为设计初值，可按实测调整）。动画不得改变命中区域或吞掉点击，不让颜色作为唯一状态信号，焦点、键盘、禁用、错误、加载、空态齐全。动态状态只跟随真实模型，未知进度不伪造百分比。仅工作台保留受控装饰动效；复用 MagicCore、LightMotes 的思想并核查本地现有实现。QtQuick.Effects、QtQuick.Particles、Shader Tools 仅在本机已有且构建验证可用时按需接入；缺失则报告，不使用未经批准的额外依赖。窗口隐藏、最小化、低动效或不活跃页面停止装饰动画，避免大面积实时模糊及虚拟化列表逐项粒子。图标优先使用现有合法 SVG，应用图标从已有本地图标提供路径获取并有通用回退，许可不清楚的第三方素材不进公开仓库。可用 Krita 或 Inkscape 做图层与 SVG，Figma/Penpot 可作为可选编辑器，不作为构建前置依赖。

### 4. 真实数据

读取真实生产模型属性、角色和 invokable，建立逐控件绑定表（组件/生产字段/证据来源/状态/交互/测试）。禁止复制图上的虚拟数值、软件版本、健康率和任务状态到产品。使用实际本地只读扫描快照和真实历史证据；没有可信来源就显示未知、未检查、未接入或阻断。区分安装/渠道候选/上游/生效版本、来源身份/信任/授权、检查/执行/核验。隔离夹具只能用于测试，必须与生产数据路径区分。不向公开仓库上传原始主机清单、路径、私有源、凭据或未经脱敏的截图。禁止真实更新、远程来源查询、提权、系统服务部署或自动更新；D-195、Omarchy、C2/B3 维持现有安全边界。
